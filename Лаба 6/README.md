# Лабораторная работа №6

Учёт детей в детском саду с PHP и MySQL.

Возможности:
- добавить ребёнка;
- посмотреть список детей;
- отсортировать список по ФИО, дате рождения, группе или дате зачисления;
- изменить данные ребёнка.

Запуск:
1. Запустите Apache и MySQL в XAMPP.
2. Откройте phpMyAdmin и импортируйте файл database.sql.
3. Откройте http://localhost/php-labs/%D0%9B%D0%B0%D0%B1%D0%B0%206/.
