# Лабораторная работа №6 — учёт детей в детском саду

## Настройка
1. Скопируйте папку «Лаба 6» в C:\xampp\htdocs\php-labs\.
2. Запустите в XAMPP Apache и MySQL.
3. Откройте http://localhost/phpmyadmin/, выберите «Импорт» и загрузите database.sql.
4. При необходимости измените настройки подключения в db.php.
5. Откройте http://localhost/php-labs/%D0%9B%D0%B0%D0%B1%D0%B0%206/.

## Реализовано
- таблица children для хранения данных детей;
- подключение к MySQL через PDO;
- добавление записей и проверка полей;
- вывод списка детей;
- сортировка по ФИО, дате рождения, группе и дате зачисления;
- редактирование существующей записи;
- подготовленные SQL-запросы.
