# Лабораторная работа №4 — компьютерный магазин

## Запуск
1. Поместите папку «Лаба 4» в C:\xampp\htdocs\php-labs\.
2. Запустите Apache в панели XAMPP.
3. Откройте http://localhost/php-labs/%D0%9B%D0%B0%D0%B1%D0%B0%204/.

## Реализовано
- форма заказа комплектующих;
- проверка имени, email и количества товаров;
- получение формы через POST;
- расчёт суммы каждой позиции и всей корзины;
- скидка 5% от 25 000 ₽ и 10% от 50 000 ₽;
- экранирование пользовательского ввода через htmlspecialchars().
