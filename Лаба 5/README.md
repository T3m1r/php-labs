# Лабораторная работа №5 — справочник городов Канады

## Запуск
1. Скопируйте папку «Лаба 5» в C:\xampp\htdocs\php-labs\.
2. Запустите Apache в XAMPP.
3. Откройте http://localhost/php-labs/%D0%9B%D0%B0%D0%B1%D0%B0%205/.

## Реализовано
- справочник из 10 городов Канады;
- фильтрация по первой букве названия;
- вывод описания и провинции выбранного города;
- строковые функции mb_strlen(), mb_substr(), mb_stripos();
- счётчик посещений, сохраняемый в visits.txt;
- common.php с данными и string-tools.php с примером обработки строк.

Для работы с кириллицей должно быть включено расширение PHP mbstring (в стандартном XAMPP оно обычно включено).
