# Лабораторная работа №5

Справочник городов Канады на PHP.

Что умеет:
- хранит список городов и провинций;
- ищет города по первой букве;
- показывает длину названия, первую букву и позицию подстроки;
- сохраняет количество посещений в visits.txt.

Для кириллицы используется расширение mbstring.
Запуск: поместите папку в C:\xampp\htdocs\php-labs и откройте её через localhost в XAMPP.
